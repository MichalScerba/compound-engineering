Uživatel má jasnou vizi: přejít od "AI-assisted coding" (Claude Code + VS Code = game changer) k "AI-orchestrated engineering" — systémům, kde AI autonomně generuje kód, testuje, deployuje, analyzuje logy, dělá code review a iteruje bez přímého vstupu.

Klíčové koncepty, které uživatel vyznává:
- **Context engineering** jako nejvíce underrated skill (CLAUDE.md, AGENTS.md, architektura repozitáře)
- **Compound leverage** — každý script/prompt/template/agent se stává násobičem pro další projekty
- **Agentní workflow** — planner → coding → testing → debugging → deployment agent s předáváním contextu
- **Vlastní AI development stack**: Claude Code, VS Code, Cursor, GitHub Actions, Supabase, Vercel, n8n

Uživatel vnímá toto jako historický moment (srovnává s internetem v 90s, cloudem v 2010).

**Why:** Chce stavět systémy, které mu pomáhají stavět firmy — ne jen jednotlivé aplikace.

**How to apply:** Odpovídat na technické otázky v kontextu systémového myšlení a compound leverage, ne jen "jak to nakóduji". Navrhovat řešení, která se stávají stavebními kameny pro další projekty.
